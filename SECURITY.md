# Security Policy

## Supported Versions

Only the latest stable release branch and official long-term stable (LTS) kernel releases receive security updates. Pre-release kernels (such as release candidates, beta builds, and development branches) are not supported with security backports or patches.

| Version | Supported |
| --- | --- |
| Latest Stable Release | :white_check_mark: |
| Official LTS Release | :white_check_mark: |
| Pre-release (RC / Beta / Dev) | :x: |
| Outdated / Unmaintained Versions | :x: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public issues, pull requests, or public forums.**

To report a vulnerability responsibly:

1. **Email Contact:** Send a detailed description of the issue to `eamon112009@gmail.com`.
2. **Details to Include:**
   * A detailed description of the vulnerability and its potential impact.
   * The kernel version(s) affected.
   * Steps to reproduce or a Minimal Working Example (MWE) / proof of concept, if available.
3. **Response Timeline:** You will receive an acknowledgment of your report within 1 week .
4. **Assessment & Resolution:**
   * **If Accepted:** The maintainers will work on a patch in a private repository and coordinate a disclosure date with you before releasing the fix.
   * **If Declined:** You will receive a response explaining why the issue was determined not to be a security vulnerability.
